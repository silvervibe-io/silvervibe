# Internationalization (i18n)

Runtime localization uses **[`@jsverse/transloco`](https://jsverse.gitbook.io/transloco/)** (Angular 22 → Transloco **9.x**). Shared catalogs and providers live in `libs/shared/i18n` (see implementation issue once scaffolded).

## Languages

| Code | Language | Role    |
| ---- | -------- | ------- |
| `en` | English  | Default |
| `nl` | Dutch    | Target  |
| `de` | German   | Target  |
| `fr` | French   | Target  |
| `el` | Greek    | Target  |
| `es` | Spanish  | Target  |

Install the recommended VS Code/Cursor extension when prompted, or from the Extensions view.

Lokalise MCP is **optional** (hosted TMS). In-repo JSON catalogs work without it; enable OAuth for `lokalise_sd` / `lokalise_pm` in Cursor → Tools & MCP if the team uses Lokalise.

## Conventions

See `.cursor/skills/transloco-i18n/SKILL.md`. Brand names (**SilverVibe**, **VibeStandup**) stay untranslated.

**Required for every UI change:** when you add or change user-facing copy, update the English catalog under `libs/shared/i18n/assets/i18n/en/` and the matching keys in `nl`, `de`, `fr`, `el`, and `es` in the same PR. Wire templates with Transloco (`| transloco` / `*transloco` / `TranslocoService`) — no new hard-coded strings.

Apps load catalogs from `/i18n/{lang}/{scope}.json` via build assets from `libs/shared/i18n/assets/i18n`. Providers: `...provideSilvervibeI18n()` in each app `app.config.ts`.
