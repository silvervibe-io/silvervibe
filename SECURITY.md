# Security

If you find a vulnerability in Silver Vibe, **do not** open a public issue.

Please report privately via the GitHub security advisory flow on
[silvervibe-io/silvervibe](https://github.com/silvervibe-io/silvervibe)
or contact the maintainer through silvervibe.io when an address is published.

We aim to acknowledge reports within a reasonable time and will credit
reporters who wish to be named (unless a fix is still private).
